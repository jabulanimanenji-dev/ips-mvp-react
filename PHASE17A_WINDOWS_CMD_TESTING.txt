PHASE 17A.3 + 17A.4 WINDOWS CMD TESTING
======================================

1. Extract the ZIP to a new folder.

2. Open Command Prompt and run:

cd /d "C:\Users\pea\ips-mvp-react-phase17a3-a4"
copy /Y .env.example .env
notepad .env
npm ci
npm run check

3. Start backend in CMD window 1:

cd /d "C:\Users\pea\ips-mvp-react-phase17a3-a4"
npm run dev:server

4. Confirm backend/database:

curl.exe http://127.0.0.1:8080/api/health

Do not continue until database is connected and ready is true.

5. Start frontend in CMD window 2:

cd /d "C:\Users\pea\ips-mvp-react-phase17a3-a4"
npm run dev

6. Open:

http://127.0.0.1:3000/services
http://127.0.0.1:3000/YOUR_ADMIN_ENTRY_PATH

7. In Platform Studio > Service Engine:
- Publish a category and service.
- Enable accepting requests.
- Add two form steps.
- Add a required question and a conditional required question.

8. On /services:
- Select the published service.
- Complete the generated multi-step form.
- Verify conditional behavior.
- Submit as a signed-in client.

9. Verify the created request in:
- Client Services
- Admin Service Operations
- Provider workflow after assignment

10. Built application smoke test:

cd /d "C:\Users\pea\ips-mvp-react-phase17a3-a4"
npm run build
npm start

Open http://127.0.0.1:8080

Never commit .env, credentials, node_modules, dist, uploads or .git.
