# Ultimate MVP Phase 11

Phase 11 combines Visual Builder 2.0 with server-enforced administrator hierarchy.

## Visual Builder 2.0

- A page registry covers every current public, client, provider, and administrator route.
- Each page has an independent governed draft design.
- Background choices include theme default, solid colour, gradient, image, or muted looping video.
- Administrators can add text, buttons, cards, banners, images, and videos.
- Blocks can be dragged across the preview canvas.
- Every block has independent desktop, tablet, and mobile position and size.
- Page padding, minimum height, and maximum content width are responsive.
- Blocks have visibility, device targeting, layer order, colour, corner, link, and accessibility controls.
- A page design can be copied to another page.
- Existing protected React interfaces remain intact beneath optional visual layers.
- Draft, preview, validation, publish, version history, and rollback remain part of the existing release workflow.

## Governed media library

- Supported images: JPEG, PNG, WEBP, and GIF.
- Supported videos: MP4 and WEBM.
- Images are limited to 8 MB and videos to 25 MB.
- SVG, scripts, and executable formats are rejected.
- Stored filenames are generated by the server.
- Public media delivery uses immutable cache headers.
- Media used by a draft or live configuration cannot be deleted.
- Upload and deletion actions are audited.
- Production media remains on the Render persistent disk through `UPLOADS_DIR`.

## Administrator hierarchy

The deployment-environment account is the immutable root Super Admin. Its password is not stored in MongoDB and cannot be retrieved or changed through the application.

Built-in delegated roles:

- Administrator: full operations without administrator ownership.
- Moderator: messages, files, support, actions, and read-only operational visibility.
- Support Agent: clients, support, messages, and relevant work visibility.
- Finance Manager: payment tracking, reports, quotes, and safe export.
- Content Designer: Visual Builder drafts and media without publishing authority.
- Audit Viewer: read-only operational, reporting, settings, and audit visibility.

The root Super Admin can create custom roles from the complete permission catalogue.

## Account controls

- Create administrators with a temporary password.
- Force the first password change before Mission Control opens.
- Assign built-in or custom authority.
- Change role or status.
- Suspend, lock, archive, or remove managed accounts.
- Reset a password without ever retrieving the old password.
- Revoke every old session after role, status, custom-role, or password changes.
- Prevent self-demotion and self-deletion.
- Prevent delegated creation of another root Super Admin.
- Record access, password, role, design, media, and governance events.

## Permission enforcement

Navigation is filtered for convenience, but the server is authoritative. Direct URLs and API requests are denied unless the signed session has the required permission. This protects orders, services, clients, providers, files, communications, support, action queues, finance, reporting, settings, design, publishing, media, exports, administrator management, and audit access.
