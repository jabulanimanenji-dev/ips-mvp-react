# IPS Platform Studio — Batch 1

Implemented the first stable Platform Studio foundation:

- Renamed Visual Builder administration to Platform Studio in the admin catalogue and navigation.
- Added a Platform Studio dashboard as the default module.
- Added live draft KPIs for categories, services, editable pages, homepage sections, enabled features, and published versions.
- Added one-click module launchers for Website, Services & Pricing, Navigation, Media Library, Feature Controls, and Publishing.
- Preserved the existing governed draft/publish/rollback workflow.
- Added responsive dashboard styling for desktop, tablet, and mobile.

The next batch should expand the Website Builder and homepage section engine rather than hard-coding a new homepage.
