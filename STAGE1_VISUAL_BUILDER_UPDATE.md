# IPS Stage 1 — Dual-Audience Access and Visual Builder Controls

Implemented in this build:

- Client/provider Sign In dropdown in the public header.
- Client/provider Sign Up dropdown in the public header.
- Responsive mobile equivalents.
- New `/join` account-type selection page.
- Join-page copy editable under Visual Builder → Content.
- Authentication-menu labels and descriptions editable under Visual Builder → Content.
- `/join` and `/become-a-provider` added to the Page Designer catalog.
- New Visual Builder → Feature Controls tab.
- Super Admin-configurable feature flags for public, client, provider and payment capabilities.
- Frontend enforcement for client registration, provider applications, client login, provider login, quote requests and service marketplace availability.
- Existing Page Designer background/image/video and responsive overlay support remains available for the newly catalogued pages.

This is the first implementation batch from the larger approved roadmap. Remaining hard-coded pages, system text, backend-level enforcement, form-builder expansion, reusable blocks, and complete feature coverage continue in subsequent stages.
