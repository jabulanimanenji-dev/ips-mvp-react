# Phase 15 — Service Platform Studio

This batch introduces a database-backed service catalog inside PlatformConfig. Super Admin can add, edit, reorder, feature, activate or disable categories and services; set pricing models and starting prices; and publish changes through the existing draft/version workflow.

The homepage Service Explorer, homepage pricing tabs and public marketplace now read the published catalog rather than hard-coded arrays. Academic services remain the flagship category with thesis, dissertation, assignment and PhD pricing preserved.
