# Ultimate MVP — Phase 1

This phase introduces one shared decision workflow across academic orders, professional services, and odd jobs.

## Delivered

- Written quote-change requests with reasons and requested adjustments
- Clarification questions and written answers
- Revision, cancellation, hold, and dispute request records
- Creator, recipient, priority, timestamps, response, and resolution state
- Quote snapshot stored with quote-change requests
- Shared questions and decisions panel in academic workspaces
- Dedicated service-job workspace for client, provider, and admin
- Proper admin quote editor with explanation and expiry date
- Audit entries and notification records for decisions

## Next phase

- Server-authenticated sessions and role authorization
- Password hashing and migration
- Enforced status-transition rules
- Shared files and messaging for service jobs
- Quote version history and expiry enforcement
- Provider acceptance, scheduling, payments, and expenses
